# Project

## Ideas

- An app to manage a gym. Users can sign into classes, there are trainers, manager

- ATS system: HR, hiring manager, applicant. Use LLM API

- Election app

- Pre-Doctor Symptom & Incident Tracker
Roles & Permissions: Patient logs symptoms, timeline, and photos; Clinician views exported read-only medical timeline reports; System Admin manages data retention and audit logs.
External API: OpenAI / Claude API (summarizes unstructured logs into structured clinical notes) or Cloudinary / AWS S3 (secure symptom image storage).

- "מה אני שווה?": משתמשים משתפים שכר בצורה אנונימית לפי תפקיד, ניסיון ואזור, וכך מתכוננים למשא ומתן.

- יומן רכב: מתעדים תדלוקים, טיפולים ותקלות, ומקבלים התראה על טסט, ביטוח וטיפול הבא. מחשב גם כמה הרכב באמת עולה לכם בחודש.
